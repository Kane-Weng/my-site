<h2 class="section-header teach">Topic 1: Comparing 3D Representations</h2>
The lab builds several 3D representations of the same ScanNet++ scene and asks which one is most useful to a robot. It compares how faithful each one is with how well it serves a downstream task.

<h2 class="section-header build">Topic 2: Open-Vocabulary Navigation on the NiFT Shuttle</h2>
For the team project, we asked whether the [NiFT shuttle](/my-site/projects/nift/) could drive to a place named in plain language, like "the bus stop", using only its LiDAR. We use OpenScene, which matches 3D points to text, to find the named object, turn it into a reachable goal pose, and hand that goal to the shuttle's navigation stack. We develop it in CARLA on the Mcity digital twin, where ground-truth labels let us measure errors, before testing on real shuttle scans.
